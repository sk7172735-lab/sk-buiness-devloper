# SK Buisness Devloper

A static business portfolio for Sandeep Karan, showcasing web development, video editing, product shoots, and online business support under the SK Buisness Devloper brand.

## Pages

- `index.html` — home
- `about.html` — about
- `skills.html` — skills
- `projects.html` — project portfolio
- `services.html` — services
- `pricing.html` — website packages and WhatsApp enquiry for other services
- `contact.html` — contact details and WhatsApp enquiry form

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript; there is no build step or package installation.

Keep the `css/`, `js/`, and `images/` folders alongside the HTML files when uploading or deploying.

## Contact form

The contact form validates the fields in the browser and opens WhatsApp with the enquiry text ready to send. It does not save submissions to a database or send email from a server.
